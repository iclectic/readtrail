ReadTrail

Privacy notice

This page is the public privacy notice for store listings. It mirrors the in-app notice and the project draft in docs/PRIVACY.md.

Summary

ReadTrail is an offline-first personal reading companion. Core library, progress, notes, goals and statistics are stored locally on your device in SQLite.

Data stored on this device

Book metadata you enter or import; reading progress, sessions and notes; goals, achievements and preferences; optional backup files you create; optional local product event counts that never leave the device unless you export files yourself.

Network use

No account is required for offline reading tracking. If you choose Search catalogues, Look up ISBN, or Scan barcode with online lookup, ReadTrail requests metadata from Open Library. Feedback email opens your mail client and is handled by the operating system.

Sharing and export

Export creates JSON, CSV or Markdown files you control via the system share sheet. Import replaces or merges local data only after explicit confirmation.

Permissions

Camera is used only to scan ISBN barcodes. Notifications are used only for an optional daily reading reminder you can disable at any time. Document picker access is used only when you import a backup or CSV.

Artificial intelligence

ReadTrail does not send your private notes to third-party AI services. Any future AI feature will be optional and will require informed consent before private text leaves the device.

Children’s privacy

ReadTrail does not knowingly collect personal information from children. Age ratings should follow store guidance for general productivity and lifestyle apps.

Accounts

ReadTrail does not create user accounts for core use. There is no cloud account deletion flow because there is no cloud account. Clearing local data is available in Settings.

Contact

Questions: support@readtrail.app
