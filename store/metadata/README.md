# Store metadata (en-GB)

Plain-text fields ready to paste into App Store Connect and Google Play Console.
Source narrative: `docs/STORE_LISTING.md`.

| File | Use |
|------|-----|
| `en-GB/name.txt` | App name |
| `en-GB/subtitle.txt` | Apple subtitle (≤30) |
| `en-GB/short_description.txt` | Play short description (≤80) |
| `en-GB/description.txt` | Full description |
| `en-GB/promotional_text.txt` | Apple promotional text |
| `en-GB/keywords.txt` | Apple keywords |
| `en-GB/release_notes.txt` | What’s New / release notes |

Feature graphic PNG: `docs/site/feature-graphic.png` (regenerate with `npm run export:feature-graphic`).
